# Thunderbird Mail Fix

เครื่องมือ PowerShell ไฟล์เดียว (มีหน้าต่าง UI) สำหรับสแกนและแก้ปัญหา Mozilla Thunderbird บน Windows แยกตามบัญชีอีเมล

A single-file PowerShell tool with a window that scans every Thunderbird mail account on a Windows PC and fixes the broken ones.

![screenshot](docs/screenshot.png)

## ปัญหาที่แก้ได้ / What it handles

| ปัญหา | ตรวจพบ | แก้อัตโนมัติ |
|---|---|---|
| "ไม่สามารถเขียนอีเมลไปยังกล่องจดหมายได้" (Unable to write the email to the mailbox) | ✅ | ✅ |
| สิทธิ์โฟลเดอร์ผิด / ผู้ใช้ไม่มีสิทธิ์เขียน | ✅ | ✅ |
| ไฟล์เมลเป็น Read-only / ถูกล็อก | ✅ | ✅ |
| ไฟล์ดัชนีโฟลเดอร์ (.msf) เสีย | ✅ | ✅ |
| ไฟล์ค้างจากการ Compact ที่ล้มเหลว (nstmp) | ✅ | ✅ |
| ไฟล์ล็อกโปรไฟล์ค้าง, ไฟล์ชั่วคราวค้าง | ✅ | ✅ |
| เมลไม่เข้า เพราะปิด "ตรวจเมลใหม่อัตโนมัติ" | ✅ | ✅ |
| แคช / ฐานข้อมูลค้นหาเสีย (ช้า, ค้นหาไม่เจอ) | – | ✅ (ตัวเลือก) |
| เชื่อมต่อเซิร์ฟเวอร์รับเมล / ส่งเมลไม่ได้ (DNS, Port, Firewall) | ✅ | แจ้งวิธีแก้ |
| ไม่ได้บันทึกรหัสผ่าน | ✅ | แจ้งวิธีแก้ |
| เมลค้างในกล่องขาออก (Outbox) | ✅ | แจ้งวิธีแก้ |
| กล่องจดหมายใหญ่เกิน 4 GB, ดิสก์เต็ม, FAT32, อยู่ใน OneDrive | ✅ | แจ้งวิธีแก้ |
| โฟลเดอร์เก็บเมล (Local Directory) หายไป | ✅ | แจ้งวิธีแก้ |

ปัญหาที่ต้องแก้ที่เซิร์ฟเวอร์หรือเครือข่าย (รหัสผ่านผิด, เซิร์ฟเวอร์ล่ม, Firewall) สคริปต์จะแจ้งสาเหตุและวิธีแก้ให้ แต่แก้เองไม่ได้

## วิธีใช้ / How to use

1. ดาวน์โหลด `Thunderbird-Fix-Tool.ps1` ไปไว้ที่เครื่องที่มีปัญหา
2. คลิกขวาที่ไฟล์ > **Run with PowerShell** (โปรแกรมจะขอสิทธิ์ Administrator เอง)
   หรือรันคำสั่ง:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Thunderbird-Fix-Tool.ps1
   ```
3. โปรแกรมสแกนทุกบัญชีให้อัตโนมัติ บัญชีที่มีปัญหาจะขึ้นสีแดงและถูกติ๊กไว้
4. กด **แก้ไขอัตโนมัติทุกบัญชีที่มีปัญหา** หรือเลือกบัญชีเองแล้วกด **แก้ไขบัญชีที่เลือก**
5. เปิด Thunderbird แล้วทดสอบ หากยังมีปัญหาในโฟลเดอร์ใด คลิกขวาที่โฟลเดอร์ > Properties > Repair Folder

### ตัวเลือก / Options
- **สร้างดัชนีโฟลเดอร์ใหม่ทั้งหมด (.msf)** – ใช้เมื่อยังพบข้อผิดพลาดซ้ำ
- **ล้างแคช + ฐานข้อมูลค้นหา** – เมื่อ Thunderbird ช้า หรือค้นหาเมลไม่เจอ
- **ยกเว้นโปรไฟล์จาก Windows Defender** – เมื่อแอนตี้ไวรัสล็อกไฟล์เมล

## ความปลอดภัยของข้อมูล / Safety

- ไม่ลบอีเมล ไฟล์ที่นำออกจากโปรไฟล์จะถูก **ย้าย** ไปที่ `Desktop\Thunderbird-Fix-Backup-<วันเวลา>` พร้อมไฟล์ log
- `prefs.js` ถูกสำรองก่อนแก้ไขทุกครั้ง
- Thunderbird จะถูกปิดก่อนเริ่มแก้ไข (โปรแกรมจะถามก่อน)
- เมื่อรันแบบ Administrator จะสแกนทุกผู้ใช้ Windows ในเครื่อง ถ้าไม่ใช่ Admin จะสแกนเฉพาะผู้ใช้ปัจจุบัน

## Requirements

- Windows 10 / 11, Windows PowerShell 5.1 (มีมากับ Windows)
- Mozilla Thunderbird (profile ใต้ `%APPDATA%\Thunderbird`)

# Thunderbird Mail Fix

โปรแกรมสแกนและแก้ปัญหา **Mozilla Thunderbird** บน Windows แยกตามบัญชีอีเมล หน้าต่างภาษาไทย
ไฟล์ **.exe ไฟล์เดียว** ไม่ต้องติดตั้ง – วางบน shared server แล้วดับเบิลคลิกได้เลย

A single-file Windows tool that scans every Thunderbird mail account on a PC, fixes the broken ones and optimizes the profile.

## ดาวน์โหลด

ดาวน์โหลด **`ThunderbirdMailFix.exe`** จากหน้า [Releases ล่าสุด](../../releases/latest)

- ใช้ได้กับ Windows 10 / 11 (มี .NET Framework 4 และ PowerShell 5.1 มาให้แล้ว)
- exe ไม่ได้ลงลายเซ็นดิจิทัล – ถ้า SmartScreen เตือน ให้กด **More info > Run anyway**
- มีแบบสคริปต์ด้วย: คลิกขวาที่ `Thunderbird-Fix-Tool.ps1` > **Run with PowerShell**

## วิธีใช้งาน

1. ดับเบิลคลิก `ThunderbirdMailFix.exe` แล้วกด **Yes** ที่หน้าต่างขอสิทธิ์ Administrator
   (กด No ก็ใช้ได้ แต่จะสแกนเฉพาะผู้ใช้ปัจจุบัน)
2. โปรแกรมสแกนทุกบัญชีให้อัตโนมัติ
   - 🟢 **ปกติ** – ไม่พบปัญหา
   - 🔴 **มีปัญหา** – ถูกติ๊กเลือกไว้ให้แล้ว
   - 🟠 **ควรตรวจสอบ** – ไม่ร้ายแรง แต่ควรดู
3. คลิกที่บัญชีเพื่อดูสาเหตุในช่อง **รายละเอียดบัญชี**
4. กดปุ่มที่ต้องการ

| ปุ่ม | ใช้เมื่อ |
|---|---|
| **แก้ไขอัตโนมัติทุกบัญชีที่มีปัญหา** | แก้ทุกบัญชีที่เป็นสีแดง แล้วสแกนซ้ำเพื่อยืนยัน |
| **แก้ไขบัญชีที่เลือก** | แก้เฉพาะบัญชีที่ติ๊กไว้ |
| **Optimize** | Thunderbird ช้า / ค้าง / ค้นหาไม่เจอ – [รายละเอียด](#optimize) |
| **ทดสอบรับ/ส่งเมล** (ช่องรายละเอียดบัญชี) | กด Get Messages ไม่ได้ / ส่งเมลไม่ออก – [รายละเอียด](#ทดสอบรับส่งเมล) |
| **เปิด Thunderbird ▾** (มุมขวาบน) | เปิดตามปกติ / **เปิดแบบไม่โหลด Add-on** (Thunderbird ค้าง/crash) / **เลือกโปรไฟล์** (เปิดมาแล้วเมลหาย) |
| **+ เพิ่มโปรไฟล์เอง** | ใช้ Thunderbird Portable หรือโปรไฟล์อยู่ที่อื่น |

หลังแก้ไขแล้ว ถ้ายังมีปัญหาในโฟลเดอร์ใด ให้คลิกขวาที่โฟลเดอร์ใน Thunderbird > **Properties** > **Repair Folder**

## ทดสอบรับ/ส่งเมล

เลือกบัญชี กดปุ่ม **ทดสอบรับ/ส่งเมล** แล้วใส่รหัสผ่าน โปรแกรมจะล็อกอินเซิร์ฟเวอร์รับเมล (POP3) และส่งเมล (SMTP) แบบเดียวกับ Get Messages / Send
**ไม่ส่งเมลจริง** และ **ไม่บันทึกรหัสผ่าน**

| ผลที่ได้ | ความหมาย / วิธีแก้ |
|---|---|
| รับเมล: สำเร็จ – มีเมลรอ N ฉบับ | เซิร์ฟเวอร์ปกติ ปัญหาอยู่ที่ Thunderbird: ลบรหัสผ่านเก่าใน Saved Passwords, ตรวจโหมด Work Offline, กดแก้ไขอัตโนมัติ |
| รับเมล: สำเร็จ – ไม่มีเมลบนเซิร์ฟเวอร์ | เครื่องอื่นดึงไปแล้ว / ตก Spam บนเซิร์ฟเวอร์ / ส่งไม่ถึง (ขอเมลตีกลับจากลูกค้า, ดูใน Webmail) |
| รับเมล: รหัสผ่านไม่ถูกต้อง | รหัสหมดอายุหรือถูกเปลี่ยน – ตรวจกับผู้ดูแลเมลเซิร์ฟเวอร์ แล้วอัปเดตใน Thunderbird |
| รับเมล: กล่องเมลถูกใช้งานอยู่ | POP3 ให้เข้าได้ทีละเครื่อง – ปิดโปรแกรมเมลเครื่องอื่น / มือถือ แล้วลองใหม่ |
| รับเมล: เซิร์ฟเวอร์มีปัญหา / พื้นที่เต็ม | ติดต่อผู้ดูแลเมลเซิร์ฟเวอร์ |
| ส่งเมล: รหัสผ่านไม่ถูกต้อง (535) | แก้ที่ Settings > Outgoing Server (SMTP) และลบรหัสเก่าใน Saved Passwords |
| ส่งเมล: เชื่อมต่อไม่ได้ | Firewall / ผู้ให้บริการเน็ตบล็อกพอร์ต – ลองพอร์ต 587 (STARTTLS) หรือ 465 (SSL/TLS) |
| ส่งเมล: ต้องเข้ารหัสก่อนล็อกอิน (530) | ตั้ง Connection security ของ SMTP เป็น STARTTLS หรือ SSL/TLS |

## Optimize

ปิด Thunderbird แล้วปรับแต่งทุกโปรไฟล์ให้ทำงานเสถียรขึ้น

| ขั้นตอน | รายละเอียด |
|---|---|
| ตรวจและบีบอัดฐานข้อมูล | ตรวจความเสียหายของไฟล์ฐานข้อมูล (SQLite) แล้วบีบอัด (VACUUM) ให้เล็กและเร็วขึ้น |
| ซ่อมฐานข้อมูลที่เสีย | ไฟล์ที่ Thunderbird สร้างใหม่ได้ (เช่น ฐานข้อมูลค้นหา) ย้ายออกให้สร้างใหม่ – ไฟล์สำคัญ (สมุดที่อยู่, กุญแจ OpenPGP, ปฏิทิน) **ไม่ลบ** แค่เตือนและเก็บสำเนาไว้ |
| ซ่อมไฟล์ตั้งค่าที่เสีย | ไฟล์ JSON ที่อ่านไม่ได้ (เช่น xulstore.json) ย้ายออกให้ Thunderbird สร้างใหม่ |
| ล้างแคช | ลบแคชและไฟล์ชั่วคราวของ Thunderbird |
| เปิด Auto-Compact | ให้ Thunderbird บีบอัดโฟลเดอร์เองเมื่อเกิน 20 MB (ไฟล์เมลไม่บวม) |
| เตือน Trash / Junk | เมื่อโฟลเดอร์ถังขยะ / จดหมายขยะใหญ่เกิน 300 MB |

**ตัวเลือกเพิ่มเติม** (สวิตช์ด้านขวาของแถบปุ่ม)
- **สร้างดัชนีใหม่ (.msf)** – ตอนแก้ไข ย้ายไฟล์ดัชนีทั้งหมดออกให้สร้างใหม่ ใช้เมื่อยังพบข้อผิดพลาดซ้ำ
- **ยกเว้นจาก Defender** – เพิ่มโฟลเดอร์โปรไฟล์เป็นข้อยกเว้นของ Windows Defender

## โปรแกรมเปิดไม่ติด?

| อาการ | โปรแกรมจัดการให้ |
|---|---|
| กด **No** ที่หน้าต่างขอสิทธิ์ Admin | เปิดต่อแบบผู้ใช้ปัจจุบัน |
| เปิดจาก shared server ผ่านไดรฟ์ที่ map ไว้ (เช่น `Z:`) | เปลี่ยนเป็น path จริง `\\server\share\...` ก่อนขอสิทธิ์ Admin |
| เปิดซ้ำ | ดึงหน้าต่างเดิมขึ้นมา – ถ้าตัวเดิมค้างเบื้องหลัง จะถามเพื่อปิดตัวที่ค้าง |
| ปิดหน้าต่างแล้วโปรแกรมยังค้างอยู่ | ปิดจริงทันที ไม่ค้างเบื้องหลัง และไม่ขวางการปิดเครื่อง |
| เปิดแล้วเงียบ ไม่มีอะไรขึ้น | แสดงข้อความบอกสาเหตุ และบันทึกไว้ที่ `%TEMP%\ThunderbirdMailFix-errors.log` |

ถ้ายังเปิดไม่ได้ ส่วนใหญ่เป็นเพราะแอนตี้ไวรัสบล็อกไฟล์ – เพิ่ม `ThunderbirdMailFix.exe` เป็นข้อยกเว้น

## ความปลอดภัยของข้อมูล

- **ไม่มีการลบอีเมล** – ไฟล์ที่นำออกจากโปรไฟล์จะถูก **ย้าย** ไปที่ `Desktop\Thunderbird-Fix-Backup-<วันเวลา>` พร้อมไฟล์ log
- สำรอง `prefs.js`, `profiles.ini`, `installs.ini` และฐานข้อมูลสำคัญก่อนแก้ไขทุกครั้ง
- ปิด Thunderbird อย่างถูกวิธีก่อนแก้ไข (รอบันทึกไฟล์ สูงสุด 15 วินาที) – ถ้าปิดไม่ได้จะไม่แก้ไขอะไรเลย
- เปิดโปรแกรมได้ทีละหน้าต่าง ป้องกันการแก้ไฟล์ชนกัน
- รหัสผ่านที่ใส่ในปุ่มทดสอบรับ/ส่งเมล ใช้ครั้งเดียว ไม่บันทึก และไม่เขียนลง log

## สำหรับผู้พัฒนา

| ไฟล์ | หน้าที่ |
|---|---|
| `Thunderbird-Fix-Tool.ps1` | ตัวโปรแกรมทั้งหมด (หน้าต่าง + ระบบสแกน / แก้ไข / Optimize / ทดสอบรับ-ส่งเมล) |
| `build.ps1` | สร้าง `dist\ThunderbirdMailFix.exe` |
| `build/Launcher.cs` | ตัวเปิดโปรแกรมของ exe (ฝังสคริปต์ไว้ข้างใน, ขอสิทธิ์ Admin เอง) |
| `build/app.manifest`, `build/app.ico` | manifest และไอคอนของ exe |
| `tests/feature-test.ps1` | Dry test ทุกฟีเจอร์ผ่านหน้าต่างจริง (มีเซิร์ฟเวอร์ POP3 / SMTP จำลอง) |
| `tests/launch-test.ps1` | Dry test การเปิดโปรแกรม การหา Thunderbird และกรณีค้าง |

**สร้าง exe** – ใช้ C# compiler ที่มากับ Windows ไม่ต้องติดตั้งอะไรเพิ่ม เลขเวอร์ชันอ่านจาก `$AppVersion` ในสคริปต์
```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

**Dry test** – ใช้โปรไฟล์จำลองเท่านั้น ไม่แตะ Thunderbird จริงในเครื่อง
```powershell
powershell -ExecutionPolicy Bypass -File .\tests\feature-test.ps1                      # แบบสคริปต์
powershell -ExecutionPolicy Bypass -File .\tests\feature-test.ps1 -Build .\build.ps1    # แบบ exe
powershell -ExecutionPolicy Bypass -File .\tests\launch-test.ps1 -Tool .\Thunderbird-Fix-Tool.ps1 -Root $env:TEMP\tblaunch -ShotDir $env:TEMP -Build .\build.ps1
```
